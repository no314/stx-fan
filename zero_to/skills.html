Zero to Home

Every zero_to app is built by Claude with three skills and a one page PRD. The skills say how an app is deployed, secured, and designed; the PRD says what the app does: its steps, contract calls, state fields, glossary, and acceptance criteria. Nothing about product behaviour lives in a skill.

Each build ends with a dated hand-off file: only learnings actually lived in that build, each tagged with the skill it feeds, whether it is a rule, a default, or an example, and one line saying where it stops applying. A later merge session reads several hand-offs against the current skills and proposes the next version of each. The skills below are shown verbatim, newest version first, with every earlier version behind its tab.
