# Incidents behind the dApp architecture rules

Dated stories with the rule each supports. The rules are in SKILL.md.

- **2026-09-03, Fastpool Max 500 fee read as 0.** The raw `fees-bips` var read 0 while `get-active-fee-bips` returned 450 (a matured pending fee). `app.leather.io/staking` fell back to the raw var whenever the richer read failed for any reason and displayed 0 percent. Rule: a failed read renders as unavailable; branch by interface. The same lineage pair showed caps `< u10000` against `<= u500` and a two-cycle delay on increases only. Rule: read every parameter from the specific deployed source.
- **2026-08, Zero to Claiming, roster missing 100 of 253 stakers.** Event scans and indexer state were unioned. **2026-10-15, tax export, pool locks outside the index.** 10 of 36 lock events for one address were sent by a pool operator and absent from the v3 principal index. Rule: indexer state and event scans answer different questions.
- **2026-08 to 2026-09, Zero to Claiming, read gate.** Rate limit per minute not per second; a 429 as a CORS error; a cached transient failure degrading a whole session; a minute of 429s from other tabs flipping a run onto 45 minutes of per-staker reads. Rules: route reads through a gate; cache only definitive answers; candidate: never fall back from a batched path on a transient refusal.
- **2026-09-10, Zero to Claiming, wrong probe.** Reader revision 2 probed `get-staker-unclaimed-rewards-for-cycle`, which holds only the snapshotted part; revision 3 reads `get-earned-staker-rewards`. Candidate: a probe includes accrual. Same date: a rejected settle batch let its payout batch run and 25 payouts failed with `u1016` and `u1013`. Candidate: dependency hold in the sign queue.
- **2026-08-14 and 2026-09-04, Zero to Claiming and Zero to Signing, two opposite correct post-condition answers.** A claim moves the manager's sBTC to the staker, so deny with an empty list aborts it; a deploy or admin call moves nothing, so deny with an empty list is right. **2026-10, Zero To BNS, `name-register`.** Deny with zero conditions passed every offline check and failed live because the contract burns its own escrow. **2026-09, sBTC gas swap, partial fill.** `eq` on the DLMM router would abort a valid partial fill, so pool 3 uses `lte`. Rule: name every movement under deny; originator only where a movement cannot be named; the code follows fill semantics.
- **2026-08 to 2026-09, Zero to Signing and Zero to Claiming, chain id 0x80000005.** A ported `connectValue` naming the retired `pox5-testnet` made wallets with a leftover profile sign with that chain id; the primary testnet rejected every transaction with a SignatureValidation mismatch while the wallet UI showed the right network. Rule: inherited constants are not pinned constants.
- **2026-08-16 to 2026-08-25, Zero To BNS, testnet reset.** BNS-V2 was gone from testnet after a reset and redeployed at the SDK-pinned address nine days later; the marketplaces have no commission contracts on testnet. Rule: a reset wipes third-party contracts too.
- **2026-08 to 2026-09, sBTC Deposit Recovery, Emily caching.** Emily kept serving the pre-registration empty response to identical GETs after a 201; two manual recovery sessions were lost before the cache-buster. Rule: polls of a cached upstream carry a cache-buster. **Fixture F, RBF.** A fee bump changed the txid, the registry went stale, and a grid search could not find the live signer key that the stale record carried. Rule: a txid identifies one attempt; candidate: lookup-and-verify beats search.
- **2026-09-29 and 2026-09-30, sBTC gas swap.** The node's fee estimator returned 632 / 632717 / 712364 uSTX for a swap that clears at 3000, and the relay refused every user; every `INTERNAL` was a Hiro 429 the relay reported generically and the app did not display; a credited Hiro key sat on a 50-per-minute plan; two requests a second apart both read the old KV state and signed sponsor nonce 5; a page polled one txid for over 30 minutes for a transaction the chain never held. Rules: the key's plan sets the budget; a txid identifies one attempt. The relay-side rules are not encoded here (sponsored-transactions skill, if created).
- **2026-09-21, sBTC gas swap, Leather mobile.** Mobile built, signed and broadcast a sponsored transaction the node rejected; the extension returned the hex. Rule: verified is per platform.
- **2026-10-15, tax export.** A 60-second window landed 46 requests in one server-side minute; a metadata 422 treated as a failure stopped a 1,684-transaction run with 76 tokens left; the stSTX formula copied from today's source went negative after the first PoX-5 cutover; two golden expectations were wrong where the recorded data was right. Rules and candidates: gate numbers in constants; 404 and 422 are answers; past-block reads per era; record first, assert second.
- **2026-10-18, Zero To BNS, deployed source versus repo.** The deployed zonefile-resolver allows resolution through the 5000-block grace period; the repository HEAD lacks it. Rule: the deployed text wins.
- **2026-09-10, Zero to Claiming, `event_limit=200`.** Every Status refresh failed silently until the 100 cap was verified live. Fact in constants.
